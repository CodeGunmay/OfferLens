# Synthetic demo dataset

`offerlens_demo_dataset.json` is a read-only export of the seeded demo database,
generated by `backend/scripts/export_demo_data.py`.

It exists so reviewers can inspect the exact data behind the demo screens
without running the stack, and so the matching output (confidence, band, status)
is auditable.

**Status of these records**

| Aspect | Reality |
| --- | --- |
| Suppliers (Atlas / Meridian / Horizon) | Fictional stand-ins created for this prototype |
| Property IDs, prices, rate plans, policies | Synthetic — plausible but invented |
| City and attraction names | Real-world anchors |
| Coordinates | Approximate |
| Confidence values | Output of the prototype heuristic on this synthetic data |
| Model accuracy | Not measured; see `docs/architecture.md` and the Analytics screen |

Do not describe this file as TBO inventory, supplier data, or as evidence of
model performance.
